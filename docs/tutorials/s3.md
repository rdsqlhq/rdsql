# S3 Object Storage Browser

## Purpose

Browse and manage objects in an S3-compatible bucket (AWS S3, Cloudflare R2,
MinIO, or any S3-compatible endpoint) alongside your databases.

## Requirements

- A bucket name and region (or a custom endpoint for R2/MinIO)
- An access key ID and secret access key with access to that bucket

## Steps

1. Click **New Connection** and choose the storage/S3 connection type
   instead of a database engine.
2. In **Bucket & Endpoint**, set the **Connection Name**, **Bucket**, and
   **Region**. For Cloudflare R2 or MinIO, set the **Endpoint** URL
   (e.g. `https://<account>.r2.cloudflarestorage.com`) — AWS S3 doesn't need
   a custom endpoint. Optionally set a **Path Prefix** to scope the browser
   to a subfolder, and choose path-style vs. virtual-hosted addressing.
3. In **Credentials**, enter the access key ID and secret access key.
4. Click **Test**, then **Save**.
5. Open the connection to browse objects in a grid/map view, preview files,
   view per-object details, and manage ACLs.

## Expected result

The bucket's contents are browsable like a file explorer, with previews for
common file types and object-level details.

## Troubleshooting

- **Access denied** — verify the key pair has the right bucket-level IAM/ACL
  permissions (list, get, and put as needed).
- **R2/MinIO connection fails** — the **Endpoint** field is required for
  anything that isn't AWS S3; double-check it's the full HTTPS URL.
- **Wrong addressing style** — some S3-compatible providers only support
  path-style addressing; toggle it in **Bucket & Endpoint** if virtual-hosted
  requests fail.
